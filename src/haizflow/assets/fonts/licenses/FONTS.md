# Bundled subtitle fonts

All bundled fonts are licensed under the SIL Open Font License 1.1 (see `OFL-BeVietnamPro-Montserrat-Nunito.txt`
for the licence text). Each font keeps its own copyright notice inside the font file. Source: Google Fonts
(github.com/google/fonts). Variable fonts were converted to static Regular/Bold instances.

Bangers, Montserrat, Be Vietnam Pro, Nunito, Anton, Baloo 2, Barlow Condensed, Lexend, Oswald, Pacifico,
Patrick Hand, Paytone One, Quicksand, Roboto Condensed, Sigmar One.

Arial Rounded MT Bold and SVN-Gilroy are licensed commercial fonts and are NOT bundled; the app uses them only
when they are installed on the computer.
